🌐 系统级 · 页面注入
未配置云端时，AI 对话默认走页面注入（浏览器内 AI 站点），零配置兜底。
☁️ 云端（OpenAI 兼容 API）
配置后 AI 提问优先走 API（流式输出 + 多轮会话）；留空则保持页面注入。API Key 仅存本机。
🗣 TTS 朗读
🔀 朗读引擎（来源）
系统语音 = chrome.tts 即时；本地 = 走本地服务 /speak；云端 = 走云端语音服务（Base URL / Key / 模型 / 音色见下方）。
🔊 系统语音
chrome.tts 系统朗读，即时零配置，无需本地服务。
💻 本地
kokoro / qwen3 本地模型走 asr-server /speak；服务地址在「🎙 ASR 识别」卡，模型在「🧩 本地模型管理」安装。
☁️ 云端
🌐 OpenAI 兼容
选择供应商自动填入 Base URL 与模型/音色建议，仍可手动修改；Azure / CosyVoice 见下方独立渠道。
🟦 微软 Azure（独立协议）
独立协议（SSML 合成 REST）：Region 填服务区域，音色为 Azure Neural 语音名（zh-CN-XiaoxiaoNeural 等）。
🔵 阿里云 CosyVoice（独立协议）
DashScope 原生协议：模型 cosyvoice-v1/v2/v3 系列，音色 longxiaochun 等。
