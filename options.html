🔌 终端桥接（Tab AI Bridge）

先运行 node bridge/server.js， 它会打印一个 Token。把 Token 填到下面并保存。桥接地址以服务启动时打印的为准（11434 被占用会自动顺延）：
· 终端（Claude Code / Cursor，Anthropic 协议）：ANTHROPIC_BASE_URL=http://127.0.0.1:11434
· 应用（Chatbox / CherryStudio / OpenSound…，OpenAI 协议）：API Host=http://127.0.0.1:11434/v1，API Key 填 Token，模型名随意

💡 默认已放行 opensound.world 与 world.opensound.local 及本机 localhost 任意端口；终端和桌面应用不受白名单限制。

💡 注入输入工具：聚焦到网页的多行输入框时右下角出现"发送"按钮，方便把内容发到 ChatGPT 等页面。

💡 提示：导入的数据会与现有数据合并，不会覆盖原有快照或版本。 版本保留数设置将在下次存档时生效。
